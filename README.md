## About

AgriGPT is an intelligent agriculture assistant that helps farmers make data-driven decisions. It provides AI-powered crop advisory, real-time analytics, and a comprehensive agro-store — all in one platform.

## Features

- 🤖 **AI Crop Advisor** — Get personalized farming advice through an intelligent chat interface
- 📊 **Analytics Dashboard** — Visualize crop performance, soil health, and weather data
- 🛒 **Agro Store** — Browse and purchase farming supplies
- 🌍 **3D Terrain View** — Interactive 3D visualization of farmland
- 🔐 **Secure Authentication** — User login, signup, and password recovery

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Framer Motion
- **Backend:** Node.js, Express
- **AI Engine:** Custom NLP pipeline for agricultural domain
- **Visualization:** Recharts, Three.js

## Getting Started

**Prerequisites:** Node.js (v18+)

1. Clone the repository:
   ```bash
   git clone https://github.com/solutiondevelopers/AgriGPT.git
   cd AgriGPT
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   ```bash
   cp .env.example .env
   ```
   Edit `.env` and add your API key.

4. Run the app:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
